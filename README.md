**VICE HEAT** is an offline GTA 6-style cover art studio, built for the [make.fun](https://make.fun) **gta6-cover-art-01 — Make GTA 6 Cover Art** competition. It runs entirely offline from static files: no network request, no build step, no library.

## The studio

- **4 layouts** — Hero Split, Four Corners, Triptych, Full Poster.
- **4 colour grades** — Sunset Blaze, Neon Nights, Golden Hour, Clean.
- **Code-drawn decorations** — striped retro sun, palm silhouettes, seeded skyline, halftone dots.
- **Bold condensed caption lettering** with outline, chromatic offset and glow.
- **Per-panel drag-to-pan crop and zoom**, one-photo-fills-all or per-panel photos.
- **PNG export** in 1080×1080, 1080×1350 and 1920×1080.

All artwork is original — no Rockstar assets. Fonts are OFL Noto Sans TTFs shipped under `app/fonts/`.

## Run it

Open `app/index.html`, or serve the folder (`npx serve app`).
